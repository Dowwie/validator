`scored_choice`. The scored-choice derivative uses the categorical argmax as its
selected class, as required by that source profile. The baseline produced

`0.5351165608794025` and Brier score was `0.3`.

probability minimum `0.7`. Equality was accepted in both cases. The below-threshold
episode changed from a raw correct class to a final abstention, producing 2 correct,
1 wrong, and 1 abstention while leaving probability scoring unchanged.

The two-episode public multi-label case matched its accepted independent oracle.
Baseline had one exact match and one wrong set. Candidate had one exact match and
one whole-episode abstention. The targeted run had one exact match. Marginal mean
binary log loss was `-ln(0.8)` and mean binary Brier was `0.04`.

The threshold run used `A=0.8`, `B=0.85`, and `C=0.3`. Equality retained `A`;
the first raw set `{A,C}` became `{A}`, and the second raw empty set remained an
answered empty set. A disjoint targeted comparison produced an empty intersection
with `no_data` metric status. Unchanged single-label and multi-label evaluations
were repeated; their comparisons had zero changed outcomes and no configuration
differences. A copied run inspected successfully from `/tmp`, using only its stored
snapshots and copied evidence.

## Discrepancies and repairs

No Validator implementation repair was required.

The first copied public single-label fixture placed its parent-relative evidence
file at the wrong private path and received `E_IO`. The private fixture layout was
corrected without changing the accepted fixture. The first scored-choice derivative
reused candidate choices that disagreed with categorical argmax and correctly
received `E_CONFIG`; the derivative was corrected to the declared scored-choice
profile before the admitted run.

Three verification-script assertions initially used the wrong output shape:
answered IDs were inferred from a nonexistent comparison field, policy rejection
reason was expected inside `final_outcome` instead of `rejection_reason`, and
multi-label outcomes were compared without their typed accounting fields. Each was
minimized against the published schema, corrected in the private verifier, and the
complete verification reran successfully. No expected value was fitted to Validator
output.
