scoring, immutable publication, and verified recomputation support relocated
inspection and comparison without the original input or evidence paths.

`steel_thread_end_to_end` copies the frozen four-row source into a temporary
tree. It runs the installed Cargo test binary through `check`, two `evaluate`
commands, run relocation and original-tree deletion, `inspect`, and `compare`.
It validates every success document against its published schema, independently
hashes each receipt result, checks the stored snapshots and distinct evidence
bytes, and checks the fixed independent oracle. It also exercises duplicate-key,
nonconforming scoring probability, evidence-tamper, and no-overwrite failures.

A passing independent review permits consideration of later task semantics. A
broken seam requires correction at that seam before expansion. This developer
record does not make that decision.
